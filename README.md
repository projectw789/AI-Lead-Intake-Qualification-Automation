# ALIQA

That name is deliberately practical. It describes an actual business workflow rather than sounding like a generic “AI project.”

By the end, I want this to be a proper end-to-end business automation, not just an LLM demo.

What it should do

Imagine a business receives enquiries from potential customers.

The finished system should be able to take something like:

“Hi, I'm looking for a website redesign for my business. We currently have an outdated WordPress site and want something more modern. We're hoping to launch within 2 months and have a budget of around £5,000.”

and automatically process it.
